# Nop.Plugin.DiscountRules.DiscountInCart

Sepet tutarı belirli bir değerin üzerinde ya da iki değer arasında olan müşterilere indirim tanımlamanızı sağlayan nopCommerce indirim kuralı (discount requirement) eklentisi.

**SystemName:** `DiscountRequirement.DiscountInCart`
**Author:** Silver Bilgi Teknolojileri

## Desteklenen nopCommerce sürümleri

| nopCommerce sürümü | Branch | .NET |
|---|---|---|
| 4.40 | `v4.40` | net5.0 |
| 4.50 | `v4.50` | net6.0 |
| 4.60 | `v4.60` | net7.0 |
| 4.70 | `v4.70` | net8.0 |
| 4.80 | `v4.80` | net9.0 |
| 4.90 | `v4.90` | net9.0 |

Kullandığınız nopCommerce sürümüne uygun branch'i indirin/klonlayın; her branch o sürüme özel, kendi başına derlenebilir tam kaynak kodu içerir.

## Kurulum

1. İlgili branch'i indirin
2. Projeyi derleyin (`dotnet build` veya Visual Studio)
3. Çıktıyı nopCommerce kurulumunuzdaki `\Plugins` dizinine kopyalayın
4. Yönetim panelinden eklentiyi bulup kurun/etkinleştirin
